## Roids/2 (202501-202501)

Playable, in a way, [here](https://mostlymaths.net/fds/roids/). This is the second iteration of an asteroids clone, inspired by Hyperoid, the first being [Roids](https://rberenguel.itch.io/roids), that one was in C++ targetting the Pimoroni PicoSystem, and transpiled to JS so you can play on the web.

Controls:

- Down to engage forward thrust, i.e. accelerate.
- Up to engage backward thrust, i.e. decelerate.
- Left/right to rotate either direction.
- Space to fire.

You can also use a gamepad, and I am working on a virtual pad, but it is wonky to use still.

I know the controls may feel "weird", but the inspiration for this was Hyperoid, by Edward Hutchins and this were the controls I got used to. If I ever come back and polish this (I kind of plan to) I will add the customizability of controls [Shotgun Pollock](https://github.com/rberenguel/shotgun-pollock) has.

## Stardust (202501-ongoing)

This is also the second iteration of an idea: Elite in a 2D universe. The first version was as a follow-up to my first version of Roids, also targetting the PicoSystem, but I quickly realised all I wanted to do was too large for a Raspberry Pico.

In the browsers I don't have such limitations, there is a lot of memory I can potentially use.

It is not "playable", but can be seen (unless the last iteration is broken) [here](https://mostlymaths.net/fds/stardust/). At the current moment there is nothing to do.

You can follow my [devlog for it in Bluesky](https://bsky.app/profile/berenguel.bsky.social/post/3lhhd3rjzzc2x).
